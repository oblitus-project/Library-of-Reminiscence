# 剧情（Story）

**定位**：剧情正文库。按世界线分线、按卷/章组织，与 [[doc/build|build]]（规格）、[[doc/guide|guide]]（玩家指南）、[[doc/interpret|interpret]]（解读文集）平级分工。

> [!note] 重要分工
> - **史书（OriginOS）** 与 PRA **并行**：同库双顶层根目录（`OriginOS/` 与 `PRA/`），史书保持自身编年结构、**只读**（游戏侧不整理、不改动、不套用 PRA 约定）；两者以双链互引（剧情页可直链史书条目）。
> - **时间轴（chronology）**：**待史书库就位后再建**——届时在 `story/chronology.md` 放"照记指针"（史书条目 ↔ 卷章 ↔ 角色），只引不誊。
> - 角色语音（大厅篇/战备篇）在 `build/character` 档案内；剧情的对白走台词，两者以双链互指。
> - 解读（interpret）属读者视角，与本库的"正文"无关。

---

## 结构与命名

```
doc/story/
├── README.md          ← 本文件（导航 + 约定）
├── main/              ← 主流世界线（对应 MAIN Characters）
├── extra/             ← 其他线（追忆图书馆 / 风纪委员会）
├── another/           ← 镜像世界线（TL 等）
├── special/           ← 联动/特殊（Blue Archive）
└── chronology.md      ← 【待建】跨库时间轴（史书条目 ↔ 卷章 ↔ 角色；待史书库就位）
```

- **文件名使用英文**（kebab-case；如 `vol1-ch01.md`）——中文名不利于双链引用（interpret 用中文名是因为它很少被引用，属例外）。
- **卷-章粒度**：默认「一章一文件」（`volN-chM.md`）；若一卷极短可合并为 `volN.md`。卷文件顶部写卷首索引（本章涉及的[[Characters|角色]]、事件存根、关卡）。

## 写作约定

1. **剧情直接写正文**，同卷内章节用标题层级（`## 章` / `### 幕`）组织。
2. 涉及战斗的段落，链接到 [[stage|关卡模板]] 与对应角色页（`[[]]` 双链）。
3. 事件类细目（联合行动等）若在 `build/event` 有存根，写作时以存根为准、自剧情页链接过去。
4. 剧情中出现的新设定（专有名词/地名/机构），优先写入 build/guide 对应体系，避免剧情节外自造术语。
