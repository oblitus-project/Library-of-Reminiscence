# 陕西科技大学附属中学
## 学校概况

陕西科技大学附属中学创办于1971年，位于陕西科技大学咸阳校区内，历经五十余载积淀，形成了鲜明的办学特色，校园环境优美，设施完备。

学校秉承“以人为本，健康发展”的办学理念，恪守"崇德笃学，惜时守纪"的校训，坚持"依法治校、质量立校、管理强校、科研兴校"，教育教学管理精细，全面深化课堂教学改革，推行学生自主管理，积极开展各项活动，培养学生特长，全面提高学生的核心素养，构建了优良的校风、教风和学风，教育教学成果显著。学校坚持五育并举，全面落实立德树人根本任务，系统开展"强国复兴有我"	"思政育人进行时"等主题活动，持续打造“大手拉小手 党建带团建”品牌，棒垒球、篮球等体育项目蓬勃发展，非遗实践、校园体育文化艺术节等活动精彩纷呈，有力促进学生德智体美劳全面发展。

学校先后获评全国青少年校园足球特教风色学校、国家级青春健康教育基地、省级名师专业成长基地学校、省级体育传统特色学校、陕西省"标准化高中"、市级文明校园等称号，办学质量与社会美誉度稳步提升。
