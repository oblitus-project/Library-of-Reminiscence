# 状态效果

状态效果是战斗的重要组成部分。
状态效果分为无计数状态效果，单计数状态效果与双计数状态效果：
- 单计数效果的计数通常为层数；
- 双计数效果同时拥有强度和层数。

> [!tip] 分类方法
> 本文档按**功能系统**分组（输出修正 / 承伤与抗性修正 / 骰子与等级修正 / 持续伤害 / 群体控制 / 生存与回复 / 特殊效果 / 角色专属效果 / 架势）。
> 每类效果以 `#pRA/类型/正面`、`#pRA/类型/负面`、`#pRA/类型/特殊` 标签区分极性；`净化`仅移除负面状态效果、`驱散`仅移除正面状态效果，二者均按此标签判定。
> 属于**资源**性质的效果（通用资源：手机、充能；角色专属资源：记忆、强哥注视、强哥风范）已移至 [[mechanism#资源|机制 → 资源]]。

### 呼吸法 P/X
#pRA/状态效果/呼吸法 #pRA/类型/正面
**下 X 次**攻击**有 (5\*P)% 的概率**产生[[mechanism#暴击|暴击]]。
[暴击命中时] 使[[#呼吸法 P/X|呼吸法]]层数-1。
[回合结束] 使[[#呼吸法 P/X|呼吸法]]层数-1。

> [!NOTE] 带有强度（p）的可叠加状态效果
> - 只增加强度时，若自身没有此状态，自动获得 1 层该效果。
> > [!example] 获得 4 级[[effect#呼吸法 P/X|呼吸法]]时，若没有[[effect#呼吸法 P/X|呼吸法]]，该角色将最终拥有 [[effect#呼吸法 P/X|呼吸法]] 4/1。
> - 层数归 0 就会移除此状态效果，已有的强度不会保留。
