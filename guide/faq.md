# 常见问题解答

> 面向已经游玩一段时间的玩家，解答进阶问题。

---

## 一、核心机制

**Q1：[[library#拼点|拼点]]的具体规则是什么？**

高速骰子攻击[[library#速度 / SPD|速度]]更低的敌人时，强制触发[[library#拼点|拼点]]。双方各掷骰子比大小，点数高的一方获胜；失败方的骰子被破坏。

[[library#速度 / SPD|速度]]相同的骰子之间**不会触发截停**，按先后手顺序分别执行行动。

**Q2：如何判断该不该[[library#拼点|拼点]]？**

观察对方的骰子点数范围。如果对方点数明显更大，可以放弃——用低速骰子打**单方面攻击**（不触发[[library#拼点|拼点]]，直接造成伤害或施加效果）。

但注意：单方面攻击会触发目标的[[library#反击|反击骰子]]（如果目标装备了带反击的卡牌）。

**Q3：单方面攻击时会发生什么？**

你的骰子直接命中目标，不会被[[library#拼点|拼点]]抵消。但如果目标装备了[[mechanism#守备卡|守备卡]]：
- [[library#防御骰子|防御骰子]]：自动触发，获得[[mechanism#护盾 X|护盾]]
- [[library#招架骰子|招架骰子]]：自动触发，反震造成混乱伤害
- [[library#闪避骰子|闪避骰子]]：自动触发，尝试闪避
- [[library#反击|反击骰子]]：自动触发，与你的骰子[[library#拼点|拼点]]

## 二、速度骰子

**Q4：[[library#速度骰子|速度骰子]]被破坏了怎么办？**

本回合不能使用，下回合重新投掷。某些技能可以修复被破坏的骰子。

**Q5：[[mechanism#技能卡|技能卡]]消耗[[library#速度骰子|速度骰子]]吗？**

不消耗。[[mechanism#技能卡|技能卡]]借用一颗空闲的[[library#速度骰子|速度骰子]]打出，打出后立刻生效，**不占用该骰子的使用资格**。
[[mechanism#能力卡|能力卡]]同理，打出后在整个战斗中持续生效。

> [!warning] [[mechanism#技能卡|技能卡]]和[[mechanism#能力卡|能力卡]]一旦打出，无法撤销。

**Q6：怒骸的骰子拼点失败会怎样？**

变成**破碎的骰子**：
- 威力固定为最小值
- 不可[[library#拼点|拼点]]
- 仍可造成伤害和施加效果
- 但[命中时 - 未破坏]类的效果不会触发
- 破碎的骰子在目标技能结束后单独使用

## 三、情感与理智

**Q7：情感等级提升有什么用？**

每次升级：
- **回满 [[library#COST|COST]]**
- [[library#COST|COST]] 上限 +1
- 攻防等级提升

关键等级的特殊收益：
| 等级 | 特殊收益 |
|:---:|---------|
| III | 每回合抽 2 张牌 |
| V | 每回合抽 3 张牌 + 恢复 2 [[library#COST|COST]] |

**Q8：[[library#理智 / Sanity|理智]]怎么管理？**

[[library#理智 / Sanity|理智]]范围 [-50, +50]，影响骰子掷出值的概率分布：

- **高[[library#理智 / Sanity|理智]]**：倾向于掷出高值，排除骰子范围的最低部分
- **低[[library#理智 / Sanity|理智]]**：倾向于掷出低值，排除骰子范围的最高部分
- **±50 极限**：必然排除极端值（最小值或最大值概率为 0）

**通常恢复[[library#理智 / Sanity|理智]]的方式：**
- 拼点胜利：+5
- 击杀敌方：+15 + 等级差/3
- 处于[[emotion#觉醒情绪|觉醒情绪]]

**通常失去[[library#理智 / Sanity|理智]]的方式：**
- 拼点失败：-2
- [[mechanism#陷入混乱|陷入混乱]]：-3/-5/-10（视[[library#情绪等级|情绪等级]]）
- 友方[[mechanism#倒下|倒下]]：-15 + 等级差/3
- 处于[[emotion#崩溃情绪|崩溃情绪]]

**Q9：士气低落和恐慌有什么区别？**

- **[[library#士气低落|士气低落]]**：[[library#理智 / Sanity|理智]] ≤ -30 且至少一半队友也 ≤ -30 时触发（向上取整，单人不触发）。[[library#理智 / Sanity|理智]]恢复至 0 以上解除。
- **[[library#恐慌|恐慌]]**：[[library#理智 / Sanity|理智]]到达 -50 且不满足[[library#情绪侵蚀|情绪侵蚀]]条件时，下回合触发。各角色有不同的恐慌效果。

## 四、情绪系统

**Q10：[[library#情绪|情绪]]克制关系是什么？**

三种基础[[library#情绪|情绪]]互有克制关系。
优势方对劣势方造成 **[[effect#迅捷 X|迅捷]]一击**（[[effect#伤害率增加 X%|伤害率增加]]），劣势方对优势方造成 **[[effect#疲软 X|疲软]]一击**（[[effect#伤害率降低 X%|伤害率降低]]）。

具体克制关系参见[[library#情绪关系|情绪关系]]图。

**Q11：[[library#情绪侵蚀|情绪侵蚀]]怎么触发？**

满足以下条件后，**下回合**自动进入对应侵蚀：

| 侵蚀类型                           | 前置[[library#情绪\|情绪]] |                                | [[doc/guide/library#理智 / Sanity | 理智]]要求 | 需要 EFW 技能 |
| ------------------------------ | ------------------------------ | ------------------------------ | ------------------------------- | ------ | --------- |
| [[doc/build/keyword/emotion#癫狂 | 癫狂]]侵蚀                         | [[doc/build/keyword/emotion#狂喜 | 狂喜]]+                           | +50    | 是         |
| [[doc/build/keyword/emotion#狂怒 | 狂怒]]侵蚀                         | [[doc/build/keyword/emotion#愤怒 | 愤怒]]+                           | -50    | 是         |
| [[doc/build/keyword/emotion#绝望 | 绝望]]侵蚀                         | [[doc/build/keyword/emotion#抑郁 | 抑郁]]+                           | -50    | 是         |

**侵蚀状态下的特点：**
- [[library#情绪|情绪]][[mechanism#固定|固定]]为该[[library#情绪|情绪]]，无法改变
- 仅可使用对应的 EFW 技能（[[mechanism#无法中止|无法中止]]、[[mechanism#无法逃脱|无法逃脱]]）
- 无视 [[library#COST|COST]] 不足限制（但 [[library#COST|COST]] 不会低于 0）
- 除[[emotion#癫狂|癫狂]]侵蚀外，固定[[mechanism#无差别攻击|无差别攻击]]

**Q12：[[library#情绪侵蚀|情绪侵蚀]]能提前解除吗？**

不能。[[library#情绪侵蚀|情绪侵蚀]]带有 **#固定** 关键词，本回合内无法被任何效果改变或移除。
侵蚀后的下个回合开始时，初始化[[library#理智 / Sanity|理智]]，退出侵蚀状态。

## 五、COST 与资源

**Q13：情感等级提升时 [[library#COST|COST]] 怎么算？**

恢复到当前 [[library#COST|COST]] 上限的值。
例如 Lv.0 上限 3，升级到 Lv.I 上限 4 后，[[library#COST|COST]] 恢复到 4。

**Q14：每回合结束可以做什么？**

战斗阶段结束后，你可以**丢弃任意张手牌**（手牌即手中尚未使用的卡牌）。
带有[[mechanism#保留|保留]]关键词的卡牌不能以此方式丢弃。

弃牌堆在抽牌堆为空时会重新洗混，组成新的抽牌堆。

**Q15：[[effect#晕眩 X|晕眩]]、[[effect#冻结 X|冻结]]、混乱的区别？**

| 状态 | 效果 | 解除方式 |
|-----|------|---------|
| [[doc/build/keyword/effect#晕眩 X|晕眩]] | 本回合[[doc/build/keyword/mechanism#无法行动|无法行动]] | 回合结束自动解除 |
| [[doc/build/keyword/effect#冻结 X|冻结]] | X 回合内无法行动 | 回合结束层数 -1 |
| [[doc/build/keyword/mechanism#陷入混乱|混乱]] | 打断当前技能 + 无法行动至下回合结束 + 全伤害抗性变为 2x | 回合结束初始化混乱抗性 |

## 六、状态效果

**Q16：层数类状态怎么叠加和衰减？**

同种层数直接相加（例如 10 层[[effect#振奋 X|振奋]] = 100% 混乱减伤）。
衰减规则：对**总层数**统一计算，而非各来源分别计算再合并。

**Q17：哪些效果无法被移除？**

所有带有 **#pRA/类型/特殊** 或 **#pRA/类型/不可摧毁** 的效果：

- [[library#情绪侵蚀|情绪侵蚀]]
- [[mechanism#固定|固定]]
- [[mechanism#无法行动|无法行动]]
- [[mechanism#标记|标记]]系列
- [[mechanism#保留|保留]]

[[mechanism#净化|净化]]只能移除 [[index#负面状态效果|负面状态效果]]，[[mechanism#驱散|驱散]]只能移除 [[index#正面状态效果|正面状态效果]]，两者均无法移除以上效果。

**Q18：[[effect#烧伤 X|烧伤]]层数怎么计算伤害？**

[[effect#烧伤 X|烧伤]]在回合结束时造成 X 点[[library#削减体力值的伤害|攻击伤害]]，然后层数减半（向下取整）。

## 七、策略提示

**Q19：新手最容易忽略什么？**

**情感等级提升太慢**是最常见的问题。如果感觉一直"卡费"，说明情感等级跟不上战斗节奏。
- 尽量触发命中、[[library#拼点|拼点]]来积累情感
- 合理规划升级时机（升级会回满 [[library#COST|COST]]）
- 利用混乱和击杀来额外回复 [[library#COST|COST]]

**Q20：[[library#拼点|拼点]]劣势怎么办？**

- 放弃[[library#拼点|拼点]]，用低速骰子打单方面攻击
- 如果能将敌人打入混乱，可以中断其后续所有行动
- 利用[[mechanism#援护 X|援护]]机制保护重要单位

**Q21：反震伤害怎么用？**

[[library#招架骰子|招架骰子]]拼点胜利时，超出值转变为**反震**，对目标造成[[library#削减混乱抗性值的伤害|混乱伤害]]，**无上限**。
如果对方攻击力高而你招架值更高，一发反震就能把对方打入混乱。

**Q22：队伍构建有什么建议？**

没有固定最优解。可以尝试不同流派：
- **单核加速**：集中资源保一个核心输出
- **多核均衡**：多个角色协同输出
- **控制消耗**：利用[[effect#震颤 X|震颤]]、[[effect#麻痹 X|麻痹]]、[[effect#封印 X|封印]]等控制链逐步消耗敌人
