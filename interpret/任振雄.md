# 任振雄：把承受变成武器的人

> 四层透镜 · 气息解读 · 第 1 篇
> 数据基准：2026-08 文档。**17 岁版本（强华篇）尚未完成**，仅作对照，勿作最终论断。

---

## 一、骨架层：他的系统是怎么转的

任振雄（[[Character1#任振雄|主篇 · 2026 届 29 班]]）的机制几乎全部围绕一个动词：**承受 → 转化**。

- **应激与怨恨**：受到混乱伤害 → 获得 [[effect#应激 X|应激]]；受到攻击伤害 → 获得 [[effect#怨恨 X|怨恨]]。**他被打，资源就会长出来**——被动本身就是"把痛苦存入账户"。
- **超载**：允许透支不超过情感等级的 COST。**把未来的自己挪到现在用**——这也是他风味文本里那套技术说明（"超载……长期可能削弱机体稳定性"）的机制实体。
- **一丝理智**：理智欲降至下限时，改为 -49（用 EIS/EFW 不触发）。**他为自己保留了一个"兜底"**——而这道兜底在他动用 EIS/EFW 的瞬间让位。也就是说：**他越是"认真起来"，越容易掉下去；而"一丝理智"只在他平时护着他。**
- **[[effect#坚持|坚持]] / 不屈**：致命伤害免疫一次；首次混乱自动解除。**他要到"非倒下不可"的边缘才允许自己倒下。**
- **白板的掌控者 / 灵活对策 / 活力满溢**：速度最低骰不可选中；每用一颗骰子下回合多抽一张；回合开始 +1 COST+1 抽。**他的系统自己养活自己。**

读法：**任振雄把自己当成一台可以维护、可以重装、可以透支的机器。** 他的一切机制都是"接受 — 转化 — 再运转"。这也是他"超载"风味的由来：性能是透支的，稳定是硬撑的，但**机器始终在工作**。

## 二、署名层：他的罪孽是一张"情绪全家福"

他的卡牌罪孽分布值得逐张看：

| 卡 | 罪孽 | 读法 |
| --- | --- | --- |
| 执行操作 / 保存导出 / 无视 / 不思观望 / 灵机一动 / 遗忘 / 抑郁 | **无标签** | 他的"日常卡"几乎全是工具性的——**他对世界的默认姿态是操作，不是情绪** |
| 睡意侵蚀 | 怠惰 II | 唯一"放松"的方式是睡到失去知觉 |
| 给我过来！ / 偿还！ | 嫉妒 II | 被逼急了才有的"讨要"——（这两张在"发火"里） |
| 发火 | 暴食 IV | 他的怒火是**吞下去的**——"咱们班里会操作电脑的不超过 3 个……[已屏蔽]还脾气不小" |
| 失落 | 忧郁 IV | "这是无法解决的问题，哪怕已经过去了一年多。" |
| 忍无可忍 | 暴怒 IV | 愤怒的顶点 |
| 讥讽 | 傲慢 IV | 他用冷漠居高临下 |
| 庄严哀悼 | 忧郁 IV | EIS 里的他依然哀悼 |
| 污血泣泪-始 / 终 | 暴食 IV | 吞掉自己 |
| 怨恨 | 嫉妒 IV（绝望侵蚀） | 妒恨与绝望在同一张卡上 |

读法：**他的情绪牌是七罪的全家福，而他的日常牌是"无标签"的。** 一个号称"万金油"的人，情绪也万金油——但他把情绪全部**拨到专用频道**：平时操作（无标签），隔一段时间爆发一次（暴食/忧郁/暴怒/傲慢轮着来）。**他的情绪不是背景音，是快捷键。**

## 三、指纹层：藏在他卡里的"维护者习惯"

- **振奋**：执行操作→下回合振奋；灵机一动→每有 1 层[[effect#振奋 X|振奋]]威力+1（最多+6）。**他靠"给自己打气"运转。**
- **守护**：执行操作（攻击后下回合守护）/ 灵机一动（下回合 2 层[[effect#守护 X|守护]]）。救济场之外，他总顺手给自己披一件。
- **应激 → 理智**（灵机一动：每消耗 50 层[[effect#应激 X|应激]]，恢复 10 理智）：**唯一把"承受"兑换回"清醒"的卡**——这是他整套系统的核心交易：受伤 → 应激 → 换回理智。
- **费用操作**：执行操作让最高费用牌 -1；思索摧毁自己一颗速度骰子换 1 COST。**他的战斗方式是"系统维护"：重装、删除、再启动。**（保存导出的风味文本更直接："其实我更喜欢直接按下 Ctrl + S。"）

读法：他不是在"战斗"，是在**维护**——维护自己、维护班级、维护那台经常坏掉的世界。他的牌感是：**忙，但有条理；累，但还能修。**

## 四、气息层：怒骸在他手里是会痛的

- **失落**（忧郁 IV）：本卡牌下所有骰子怒骸；**被破坏的骰子使用时威力 -3**；其中一颗还挂着截除。
- **忍无可忍**（暴怒 IV）：同上——所有骰子怒骸，被破坏时威力 -3。
- **至终的警告**（EFW 狂怒情绪侵蚀）：减算骰子×怒骸。

读法：**他的不屈是"会痛的"——怒骸不破坏时扛住，被破坏的怒骸还会反噬自己的威力（-3）。** 别人的怒骸是"我就是打不碎"；他的怒骸是"打碎了，我也要咬着牙继续用，只是会更痛"。**这种"带代价的不屈"，比任何一句台词都更像他。**

而他 **17 岁（强华篇）的怒骸同样不少**——但全部"不痛"。对照着读：

| | 17 岁 · 强华 | 18 岁 · 实验 |
| --- | --- | --- |
| 怒骸的位置 | 医疗（支援：技术辅助）／闪避（逃避苦痛）／群体攻击 ×4（无忧无虑，狼心狗肺） | 愤怒/失落的骰子（忍无可忍、失落、至终的警告） |
| 怒骸的性质 | **无代价的不屈**（被破坏不吃惩罚） | **代价的不屈**（被破坏的骰子威力 -3） |
| 情绪状态 | 无忧无虑地睡与逃（睡意侵蚀／逃避苦痛／狼心狗肺） | 清醒地痛（应激／怨恨／一丝理智） |

> 17 岁版本已于 2026-08 完整落地。现在可以看得很清楚：**他 17 岁的怒骸全部"不痛"**——治疗的怒骸、逃逸的怒骸、躺平的怒骸（无忧无虑的群体攻击，还带强效偏转——怠惰的空头支票）；**18 岁的怒骸开始"会痛"**（-3）。**同一种不灭，从"单纯地硬"，长成了"硬过之后还要继续用"。**

## 五、收束：一个人，三种承受

17 岁：**他还没被伤过。** 他睡（睡意侵蚀／深度睡眠）、他逃（逃避苦痛——"可是，最后又能逃到哪里去呢？"）、他"狼心狗肺"地没事下去（无忧无虑，狼心狗肺）——而周边已经开始哀声载道："真羡慕他还能一直这样没事下去……虽然他的努力程度比不上其他人一根，但我还是很佩服。"他的癫狂是派对（狂欢："人们放下手中的事，投入到这一份欢乐之中"）。
18 岁：**他醒了，但痛了。** 应激与怨恨长出来，"一丝理智"护住他；他的 EVW 从"狂欢"扩展到"至终的警告 / 怨恨"——也就是从癫狂走向暴怒与绝望。
之后：**他把剩下的也吞掉了。** 污血泣泪（暴食 IV）——"为了接受公平的惩罚，我将愿意承担这种责任"；直到执迷之人（扭曲 EIS）说："其实就是暴走了而已。"

> 所以他的机制语言只有一句：**"你们把伤害给我吧——我会把伤害变成武器；如果这样还不够，我就把自己也加上去。"**
>
> 他是个纯真的人，一个把"纯真"用计算机术语运营的人。这大概就是为什么他的 EIS 叫"自我的纯真"：**无论重装多少次，他的系统盘永远不会格式化。**
