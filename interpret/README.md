# 角色叙事解读（Interpretation）

**定位**：角色叙事解读文集。这里收集的是**读者视角**的解读书稿——讨论稿、手记、随笔性质，**不参与**数值、机制与设定的定义（那些归 [[doc/build|build]] 与 [[library|library]]）。

> [!note] 声明
> - 每一篇都是"某一时刻的读法"，可能与创作者意图不符——**以开发者意见为准**。
> - 文中引用的卡牌、被动、数值均以对应角色文档为准；角色更新后，解读需相应修订（文末标注"待更新"）。
> - 解读方法常用**四层透镜**（见下），但不强制；每篇自由选用。

## 四层透镜（常用方法）

| 层   | 载体                              | 性质  | 用途                  |
| --- | ------------------------------- | --- | ------------------- |
| 骨架  | 机制/数值                           | 可算  | 角色的"存在方式"：他的系统是怎么转的 |
| 署名  | [[sin\|罪孽]]属性 | 可查  | 角色在每个瞬间的情感签名        |
| 指纹  | 状态效果偏好                          | 可统计 | 设计者藏在卡里的小心思         |
| 气息  | 骰子特性风味                          | 不可控 | 这颗骰子在那一刻的性格（如怒骸＝不屈） |

> [!tip] 气息层注意
> 骰子特性因平衡性广泛分布，**不构成系统性映射**；气息只用于"这一张牌、这一颗骰子的瞬间肖像"。
