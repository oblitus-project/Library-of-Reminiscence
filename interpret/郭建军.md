# 郭建军：一座燃烧到最后的灯塔

> 数据基准：2026-08 文档。**作者确认：其图像已基本齐备**（常态 · 见微色霸气 · 绽放 EIS），不会再有新面貌——本文可以写"定稿"。

## 〇、三张脸：换档，而非刻度

与[[任振雄|任振雄]]不同，郭建军**不跨卷**——他没有"17 岁/18 岁"的年份版本。他的三种姿态是**同一时刻的不同显现层级**：

| 形态 | 性质 | 写在文档里的样子 |
| --- | --- | --- |
| 常态 | 他自己 | 平心静气、燃烧热血、深藏不露 |
| 见微色霸气 | **不是 EIS**——学生命名的"狂暴模式"，他自主开启（"使用时使自身生气"链） | 暴怒/盛怒被动；"我说了多少遍了"系列 |
| 绽放 EIS 至终的纯洁工匠 | 真·完全显现（绽放） | 全库**最深预支**（成长系数 1.106→1.095，-0.011） |

所以他的叙事语言不是"锚与刻度"，而是**"换档与预支"**。

## 一、骨架层：开局即尾声

- **精疲力竭**：[首次开启战斗] 失去**上限 75%** 的体力——"这名角色已经劳累过度。"
- **脆弱不堪**：[首次开启战斗] 失去**上限 50%** 的混乱抗性——"这名角色已经疲惫不堪。"
- **疾病缠身**：速度固定为最小值；攻击骰子最终威力-1——连骰子都慢了。

**他走进来的时候，就已经烧掉了大半。** 而他的补偿机制全是"**可以更痛**"型的：

- **燃烧热血**：不会因烧伤使体力低于上限 10%（烧伤＝怒气，怒气＝血量，但烧不穿底）；
- **[[effect#坚持|坚持]]**：致死伤害无视一次（每场 1 次）；**不屈**：首次混乱自动解除并恢复 50% 抗性；
- **再撑一会**：2 回合内承伤率 -30%——"他还能再撑一会，但这显然不会太久。"
- **怒不可遏**：处于[[emotion#生气|生气]]+ 时，[[effect#烧伤 X|烧伤]] ≤10 层 → 获得 15 层；>10 层 → 消耗 10 层恢复 1 COST。**他的 COST 是怒火给的**：越生气越能出牌，越出牌越自燃。

读法：他的骨架就是一句"**用最后的血换最多的课**"。数值上他一点"余地"都没有——所有的余地都是"我还想再撑一会"。

## 二、署名层：暴怒阶梯，与绽放的"七罪全席"

**常态 / 见微色霸气**：暴怒 I→IV **完整阶梯**，且每一级的卡名都是老师的话——

> 我都坚持了！（I，病号跑操）→ 还在我行我素！（II）→ 最后就是把你们自己给害了！（II）→ 我无所谓！（III）→ 不想待回去！（III）→ 我说了多少遍了 / 讲的东西都喂狗了 / 不要给自己找麻烦 / 你就接着混，没事，准备上高五吧 / 你看看你们！ / 发火（IV）

中间缀着忧郁（谨言慎行 III、"我实在是坚持不住了" IV）与暴食（华丽讲演 IV、你们自己看着办 IV）——**一个温和的人，把七成情绪都写在了"为什么这些孩子就是不听"上。**

**绽放 EIS 至终的纯洁工匠**：**七罪全席**——

| 罪孽        | 相关卡牌                           | 读法                                 |
| --------- | ------------------------------ | ---------------------------------- |
| 色欲 III/IV | 教授技法 / 指名谈话 / 指点迷津             | **"想要给予"**——他最终的欲望是教学的欲望           |
| 忧郁 II/IV  | 把时间交给你们 / 坚定决心                 | 沉沦与自愈                              |
| 怠惰 IV     | 你得警醒，这么下去可不行 / 反对盲目刷题          | **放弃式训诫**——怠惰的顶点不是放弃吗？不，是"你们自己看着办" |
| 暴怒 III/IV | 好好反思你们自己！/ 你们自己看着办！/ 发火 / 怒火直指 | 怒气仍然是最响的声音                         |
| 暴食 IV     | 你们自己看着办（特殊）                    | 把一切咽下                              |
| 嫉妒 III    | 恐怖                             | 整桌唯一一张"怕"                          |
| 傲慢 IV     | 绽放 EIS 显现：至终的纯洁工匠              | 至终一击即终极傲慢                          |

读法：**"至终的纯洁工匠"不是无爱无恨的干净——他是用全部七种情绪，把课打磨到最后一秒的人。** 一个班七种人，一个老师七罪俱全，这个对应比任何角色都准。

## 三、指纹层：全库唯一"反向转化"体系

任振雄的指纹是"承受→转化"；郭建军的指纹是**"负面→正面、攻击→治疗"**，全库独一份：

- **沉沦改写**：绽放中他受击时**恢复理智**、层数减至 1/3；回合结束获得承伤率降低——"沉沦在他身上变成补给"；
- **震颤衰减减缓**：引爆后层数只衰减到 **90%**（而非 2/3）；更高等级**不再衰减**——他震得比谁都久；
- **@85 级**：选中己方单位作为攻击目标时**不造成伤害，改为恢复**——教师的攻击，打在学生身上就是课；
- **@90 级**：所有骰子可选己方为目标；**只要有友方在场，自身体力不低于 1 点**——"他的坚持不是为了自己，而是为了还有学生在看他"。

读法：这是全库最温柔的机制设计——**他甚至不允许自己的"伤害"变成伤害。**

## 四、气息层：怒骸在他手里是"教具"

**常态怒骸**（全部是教学里不肯咽气的话）：

- 分享经历（闪避·怒骸）、华丽讲演（AW.9·怒骸）——讲课讲得比谁都持久；
- **我说了多少遍了，就是不听！**（AW.6·怒骸）——**打不碎的说教**，这就是这颗怒骸的完整注脚；
- 我都坚持了！（AW.6·怒骸）、不想待回去！（AW.6·怒骸）——倔强的两堂课；
- **不要给自己找麻烦**（消耗 4 层烧伤 → 本骰子怒骸）——他的愤怒需要烧自己的血换"再讲一遍"。

**绽放怒骸**（他把"打不碎"用在了每一件教学用具上）：

- **教授技法**（怒骸＋截除）：目标用怒骸/远程/守备骰时每颗 +5 基础威力——**看穿学生的路数，然后拆掉它**；
- **指名谈话 / 指点迷津**（**治疗骰·怒骸**）：全库只有他，让"治疗"怒骸——治不好的课，他再治一次；
- **备课**（防御·怒骸）；**你得警醒，这么下去可不行**（对决→截除）；**反对盲目刷题**（怒骸）——每张都是"我把话放这儿，你砸不碎"。
- **坚定决心**（怒骸，目标用守备骰→基础威力+60 且**可抹杀**）——课堂上你敢防守，我就把这一课永远删掉；
- **至终一击**（怒骸＋截除＋抹杀＋0 费＋消耗＋无法逃脱＋理智逆向，[攻击后] 下回合**无法行动**）：不屈×吞噬×抹除三合一——**"我用完这一击就倒下。""而这一切，是免费的。"**

读法：别人的怒骸是"我就是打不碎"；他的怒骸是"**我讲完了，你听不听，我都要讲完。**"

## 五、收束：从"病号跑操"到"至终一击"

这是一条完整的史书链条——每一环都是真的：

1. **病号跑操**："我一个病号都去操场了，你们 6 个，美美在教室里待着！"
2. **27 人罚站**："没交作业的，全部站到后面去！"——"全班 67 人，后面站了整整 27 人。"
3. **冷汗直流**："无数个症状都表明，我不能这么做了……可是还有答应的事项没有完成，**领导也无视了我的请求**……"
4. **辞呈**："……但是，必须去做。我最终向年级部提交了辞呈。我真的很遗憾，没能陪大家坚持到最后。"
5. **至终**：绽放 EIS 的"把时间交给你们""你得警醒，这么下去可不行""反对盲目刷题"——以及那张 **0 费、用完全场、打完倒下**的至终一击。

**0 费**不是强度的写法，是**爱的写法**：他的课从来不收钱，连最后一课也不收。**"消耗"**——他只教这一次；**"攻击后无法行动"**——他终于可以休息了。

而这根脊柱的最后一根钉子，他在风味文本里自己钉下了：*"**互相体谅。**这是他常说的一句话。"*——"面对学校的欺压、生活的不如意也只是抱怨，面对学生'弱智'的问题丝毫没有不耐烦，而是充满热情。"

> 所以郭建军的魅力不需要包装：**他不需要"被喜欢"，他只需要"被记住"——而这个游戏，就是他的纪念册。**
>
> 开发者评论里写："学校真的不配拥有这样好的老师。"——这句话，就是本篇解读的全文。
