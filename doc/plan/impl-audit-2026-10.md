# 机制实现差距清单

> [!info] 这份清单是什么
> 把 `doc/` 里**已经写定的机制**逐条与 `Scripts/` 的**实际算法**对照，标出「文档怎么说 / 代码怎么算 / 差在哪」，
> 并给每一条标注**变更类型** —— 因为这批改动的性质不同，混在一起排期就会排错。
>
> **快照时点**：文档 = 2026-10-12 03:00（`update.md` 末条）；代码 = 2026-09-25 01:04（最后一次编译产物的时间）。

> [!important] 核心判断（2026-10-12 开发者裁定后订正）
> **2026-10 这批改动的主体不是「数值没跟上」，而是「算法与数据结构变了」。**
> 有些是改了数字也解决不了的 —— 它们要求引擎换一套组织方式：
> 场地专属 EIS 卡牌与独特场地效果需要**新的卡牌归属概念**；治疗骰改百分比恢复需要**重写治疗流程并新增乘区**；
> EIS 冷却改情感充能需要**换掉"回合数递减"这个模型**。
>
> **因此本清单的首要用途不是"改数值"，而是"补结构"。** 变更类型分三类：
>
> | 类型 | 含义 | 举例 |
> | --- | --- | --- |
> | **数值** | 只改常量 / 公式系数，结构不动 | 守备骰收益改按上限比例 |
> | **算法** | 换一套计算或判定流程 | 治疗流程（威力 → 恢复比例 → 三乘区 → 逐目标换算）· 情感充能 CD |
> | **结构** | 需要新的数据模型 / 新的归属关系 / 新的聚合层 | 场地卡牌体系 · 团队情感等级 · 多目标 |
>
> **职责分层**：`Data/*.json` 的内容由**文档侧的生成系统**负责；`Scripts/` 的算法与结构由**引擎侧**负责。
> 本文档下列各处已按这两层分别标注，避免把「管线未跟上」当成「机制没实现」。

> [!note] 两类 `??` 与自命名骰 —— **不是缺口，不要动**
> - `??(数字)` / `???(数字)`：**实战中玩家看不到该数值**，是特例写法，**如实保留即可**（24 条）
> - 自命名骰（`凝视` / `成为：博士` / `慈悲` …）：**根本不算骰子**（连数字都没有），不该走骰子通道（13 条）
>
> 这两类此前被本文档误列为「待处理缺口」，已订正。

## 零、阻断级偏差：生成物与文档不一致

> [!danger] 这两条不修，任何「按文档实现」都是空中楼阁
> 生成物 `Data/*.json` 的时间戳是 2026-10-12（比代码新），**看起来是同步的**，但实际内容与文档有结构性缺口。

### 0.1 冷却写法 `X CD +Y` 整批丢失

| 项 | 内容 |
| --- | --- |
| **文档** | `library.md` L255-262 定义：EIS 卡牌冷却改为**情感充能** —— `7 CD +3` = 首次积累 7 点情感可用，此后每次 +3。全库 107 处（含 `13 CD +4` / `2 CD +8` / `19 CD +2` / `10 CD +5` 等）。 |
| **导入器** | `Tools/doc-import/parse-docs.mjs` L120：`const mCd = seg.match(/^(\d+)\s*CD$/)` —— **正则只认 `X CD`，不认 `X CD +Y`**。不匹配的片段落进 `__unknown`。 |
| **生成物实证** | `cards.json` 里 `cooldown` 字段 479 张卡**只有 3 种取值**：`0`(472 张) · `99`(4 张) · `1`(3 张)。**没有任何 `+Y` 信息**。 |
| **C# 侧** | `CardData.Cooldown` 是 `int`；`CardDbJsonLoader` L272 `Cooldown = dto.cooldown`；`Deck.cs` 按整数递减。**数据模型装不下 `X + Y` 两段。** |
| **后果** | 全部 EIS 卡牌的冷却在引擎里等于「没有冷却」或「永不就绪」，情感充能机制无从实现。 |

**要改的地方**：导入器正则（含 `alsoAt` 情形）→ `CardData` 加 `CooldownCharge` 字段 → `CardDbJsonLoader` 映射 → `Deck`/`Combatant` 的冷却判定改走情感计数。

## 七、结论

**2026-10 这批改动的主体是「算法与数据结构变了」，不是「数字没跟上」。**

有些是改数字解决不了的 —— 场地专属 EIS 卡牌与独特场地效果需要**新的卡牌归属概念**（卡不再只属于角色，还属于楼层）；治疗骰改百分比恢复要**重写治疗流程并新增乘区**；EIS 冷却改情感充能要**换掉"回合数递减"这个模型**。
