# 追忆图书馆 文档导航

本文对 `doc/` 下各文档与目录进行定位说明，帮助新成员快速找到所需信息。

---

## `doc/update.md` — 更新记录

按时间记录设定与文档的变更（新增 / 修改 / 影响）。**「影响」一栏是解读修订的依据**——角色更新后，相关解读需按此标注「待更新」。

---

## `doc/build/` — 构建规格

游戏设计蓝图，定义实体数值与规则。面向开发者。

### `build/` 根目录文档

| 文件 | 定位 |
|------|------|
| `BOSS.md` | 头目角色构建（以 Binah 为例） |
| `Character.md` | 可玩角色构建模板/实例 |
| `Event.md` | 特殊事件（联合行动）存根 |
| `ExCharacter.md` | 额外角色：其他时间线的角色 |
| `Example.md` | 角色创建母版（模板） |
| `SlayCharacter.md` | 爬塔模式角色构建 |
| `SpCharacter.md` | 特殊 NPC/剧情战斗角色 |
| `Stage.md` | 关卡设计模板 |
| `Unit.md` | 普通单位/敌人构建模板 |

### `build/card/` — 卡牌定义

| 文件 | 定位 |
|------|------|
| `iron.md` | 铁血战士 的卡牌 |
| `upg-iron.md` | 上述卡牌的升级版（+） |
| `curse.md` | 诅咒卡牌 |
| `status.md` | 状态卡牌 |

### `build/keyword/` — 关键词体系

| 文件 | 定位 |
|------|------|
| `index.md` | 索引与分类映射 |
| `sin.md` | 罪孽属性（卡牌的情感签名：类型 / 强度） |
| `mechanism.md` | 核心机制（基础状态） |
| `effect.md` | 状态效果词典 |
| `emotion.md` | [[doc/guide/library#情绪|情绪]]系统定义 |

## `doc/story/` — 剧情

剧情正文库（按世界线分线、按卷/章组织）。史书（原始记录）为独立库，不在此处。

| 文件 | 内容 |
|------|------|
| `README.md` | 剧情库章程（结构 / 命名约定 / 分卷路由表 / 时间轴速记） |
| `main/` · `extra/` · `another/` · `special/` | 各线卷文件（待写） |

---

读者视角的角色解读书稿（讨论稿、手记，不参与设定定义）。
